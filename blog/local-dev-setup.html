本地开发环境搭建指南：Node.js + VS Code + Git

发布日期：2026-09-08  |  分类：开发环境  |  阅读时间：8分钟

为什么需要本地开发环境？

本地开发环境是程序员日常工作的基础。一个好的开发环境可以大幅提升工作效率，减少不必要的麻烦。

安装 Node.js

Node.js 是 JavaScript 运行环境，几乎所有前端工具都依赖它。访问 nodejs.org 下载 LTS 版本安装。

# 验证安装
node --version
npm --version

安装 VS Code

VS Code 是目前最流行的代码编辑器。推荐安装的扩展：

  • ESLint - 代码质量检查
  • Prettier - 代码格式化
  • GitLens - Git 增强
  • Live Server - 本地开发服务器

配置 Git

git config --global user.name "你的名字"
git config --global user.email "your@email.com"
git config --global core.autocrlf true

常用命令行工具

  • PowerShell：Windows 默认终端，功能强大
  • Warp：新一代 AI 驱动的终端
  • Tabby：开源终端工具，支持 SSH 管理
