如何用 Cloudflare Pages + AdSense 搭建零成本网站赚钱

发布日期：2026-09-08  |  分类：建站教程  |  阅读时间：10分钟

为什么选择 Cloudflare Pages + AdSense 组合？

对于想要通过网站获得被动收入的个人创作者来说，Cloudflare Pages 和 Google AdSense 是最佳的免费组合：

  • Cloudflare Pages：永久免费静态网站托管，全球 CDN 加速，自动 HTTPS，每日 500 次构建
  • Google AdSense：全球最大广告平台，按点击付费（CPC），月收入可达数百至数千美元
  • 零成本：无需购买服务器，无需技术门槛，纯前端网站即可运行

第一步：准备 Cloudflare 账号

访问 dash.cloudflare.com 注册免费账号。Cloudflare 免费版已包含：

  • DNS 管理（可添加自定义域名）
  • 全球 CDN 加速
  • 免费 SSL 证书
  • 基础的 DDoS 防护

如果你有自定义域名（如本博客使用的 .cc 域名），需要在 Cloudflare 中添加 DNS 记录指向 Pages 项目。

第二步：创建 GitHub 仓库

在 GitHub.com 创建一个新的公共仓库，将你的网站代码上传。推荐的项目结构：

  • index.html — 首页
  • assets/style.css — 样式文件
  • assets/*.js — 工具脚本
  • blog/ — 博客文章目录
  • README.md — 项目说明

第三步：连接 Cloudflare Pages

登录 Cloudflare Dashboard，进入 Workers & Pages → Create application → Pages → Connect to Git。选择你的 GitHub 仓库，配置构建设置：

  • 构建命令：留空（纯静态网站无需构建）
  • 输出目录：留空（默认根目录）
  • 构建缓存：默认即可

点击 Save and Deploy，Cloudflare 会自动部署你的网站。每次推送到 GitHub 都会触发重新部署。

第四步：绑定自定义域名

在 Cloudflare Pages 的项目设置中，进入 Custom Domains → Set up a custom domain。输入你的域名后，Cloudflare 会自动添加所需的 CNAME 记录。确保你的域名 DNS 已托管在 Cloudflare 上。

第五步：申请 Google AdSense

AdSense 申请注意事项：

  • 网站内容：至少 15-30 篇原创高质量文章，纯工具站通过率极低
  • 网站年龄：建议域名注册满 3 个月以上再申请
  • 隐私页面：必须包含隐私政策、关于页面、联系我们页面
  • 用户体验：页面加载快、移动端适配良好

申请通过后，在 Cloudflare Pages 的自定义域名下插入 AdSense 代码即可开始盈利。

盈利策略建议

  • 工具+内容组合：实用工具吸引流量，博客文章提供内容深度，两者结合提高 AdSense 通过率
  • 中文 SEO：针对中文关键词优化，竞争相对较小
  • 持续更新：定期添加新工具和文章，保持网站活跃度

本网站就是按照此模式构建的——以二维码生成器为核心工具，搭配 QR 码技术博客文章，目标是通过 AdSense 实现被动收入。
