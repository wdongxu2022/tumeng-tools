Cloudflare Workers 入门指南：从零搭建免费在线工具网站

发布日期：2026-09-08  |  分类：建站教程  |  阅读时间：10分钟

什么是 Cloudflare Workers？

Cloudflare Workers 是 Cloudflare 提供的边缘计算平台，允许你在全球 300+ 个数据中心运行 JavaScript/TypeScript 代码。其免费额度非常慷慨：每天 10 万次请求、每月 10GB 读取/1GB 写入。

Workers 适合做什么？

  • 静态网站托管：通过 Wrangler CLI 部署静态 HTML/CSS/JS 文件
  • API 代理：绕过 CORS 限制，代理第三方 API
  • 边缘重定向：根据地理位置或用户代理进行智能路由
  • 小型 Web 应用：运行纯前端的在线工具

部署步骤

第一步：安装 Wrangler

Wrangler 是 Cloudflare 官方 CLI 工具，用于管理 Workers 项目。

npx wrangler login
npx wrangler init my-project

第二步：配置项目

在 wrangler.toml 中配置 Worker 名称、路由和静态资产目录。

[pages]
branch = "main"
dist = "."

[env.production]

第三步：部署

npx wrangler deploy

绑定自定义域名

在 Cloudflare Dashboard 中为你的域名添加 CNAME 记录，指向你的 Workers 子域名，即可实现自定义域名访问。

为什么选择 Cloudflare Workers？

  • 永久免费额度足够个人项目使用
  • 全球 CDN 加速，无需额外配置
  • 支持自定义 SSL 证书
  • 与 Cloudflare Pages 无缝集成
  • 无需服务器维护，零运维成本
