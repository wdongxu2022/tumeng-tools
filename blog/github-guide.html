GitHub 入门教程：从零开始掌握版本控制

什么是 Git 和 GitHub？

Git 是一个分布式版本控制系统，用于追踪文件变更。GitHub 是基于 Git 的在线代码托管平台，提供协作开发、代码审查等功能。

基本工作流程

  1. 初始化仓库：git init 或在 GitHub 创建新仓库
  2. 添加远程地址：git remote add origin [URL]
  3. 提交更改：git add . → git commit -m "描述"
  4. 推送到远程：git push origin main

常用命令速查

命令说明
git clone [url]克隆远程仓库
git status查看工作区状态
git add .添加所有更改到暂存区
git commit -m "msg"提交更改
git push推送到远程
git pull拉取远程更新

分支管理

使用分支可以并行开发不同功能而不影响主代码。常用命令：git branch 查看分支、git checkout -b 创建分支、git merge 合并分支。
